# 🦐 Automated Shrimp Farming System

An IoT-based automated shrimp farming system designed to monitor and control shrimp-farming operations using an Android application, ESP32, Raspberry Pi, sensors, relays, and camera monitoring.

The system is designed to provide real-time monitoring, automated equipment control, and remote observation of the shrimp-farming environment.

---

## 🚀 Features

- 📱 Android application for monitoring and control
- 📡 ESP32-based sensor and equipment control
- 🌡️ Water/environment parameter monitoring
- ⚡ Relay-based control of connected equipment
- 📷 Camera monitoring using Raspberry Pi
- 🧠 Automated farming operations
- 🔵 Bluetooth communication between the Android application and ESP32
- 💾 Data storage and monitoring
- 🔔 Notifications and status monitoring
